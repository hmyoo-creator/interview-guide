# 올리브인터내셔널 인터뷰 가이드

후보자에게 보내는 전형별 인터뷰 가이드 페이지예요.

| 전형 | 주소 |
| --- | --- |
| 인턴 | `사이트주소/intern` |
| 정규직 | `사이트주소/member` |
| 정규직 리더 | `사이트주소/leader` |

## 문구 고치기

문구는 모두 `content` 폴더에 있어요. 다른 폴더는 건드리지 않아도 돼요.

| 파일 | 내용 |
| --- | --- |
| `content/common.js` | 세 페이지에 모두 들어가는 내용 (인사말, 준비 사항, 오시는 길, 도착 후 안내, 연락처, 공통 FAQ, 하단 문구) |
| `content/intern.js` | 인턴 진행 방식, 인턴 전용 FAQ |
| `content/member.js` | 정규직 진행 방식, 정규직 전용 FAQ |
| `content/leader.js` | 정규직 리더 진행 방식, 리더 전용 FAQ |

### GitHub에서 고치는 순서

1. 고칠 파일을 열고 오른쪽 위 연필 아이콘(Edit)을 눌러요.
2. 따옴표 `" "` 안의 문구만 바꿔요.
3. 오른쪽 위 **Commit changes**를 눌러 저장해요.
4. 1~2분 뒤 사이트에 자동으로 반영돼요.

### 지킬 것

- 줄 끝의 쉼표 `,`는 지우지 않아요.
- 굵게: `**이렇게**`
- 줄바꿈: `\n`
- 문장 안에 큰따옴표가 필요하면 `\"`처럼 씁니다.
- 항목을 추가할 때는 바로 위 항목을 통째로 복사해서 붙여넣고 문구만 바꿔요.

저장 후 페이지에 "페이지를 불러오지 못했어요"가 보이면, 안내된 파일에서 쉼표나 따옴표가 빠진 곳을 찾아 고치면 돼요. 바로 전 상태로 되돌리려면 파일의 **History**에서 이전 버전을 확인할 수 있어요.

## 사진 바꾸기

`assets` 폴더에 **같은 파일 이름**으로 다시 올리면 바뀌어요.

| 파일 | 위치 |
| --- | --- |
| `assets/logo.png` | 맨 위 회사 로고 |
| `assets/map.jpg` | 오시는 길 지도 |
| `assets/elevator.jpg` | 도착 후 엘리베이터 사진 |

## 폴더 구조

```
index.html          전형 선택 화면
intern/index.html   인턴 페이지 (수정 불필요)
member/index.html   정규직 페이지 (수정 불필요)
leader/index.html   정규직 리더 페이지 (수정 불필요)
content/            ← 문구는 여기서만 고쳐요
assets/             로고·사진, 디자인(style.css), 화면 그리는 코드(render.js)
```
